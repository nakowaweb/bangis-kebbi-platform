# Approved homepage redesign

## Goal
Rebuild only the BangisKebbi.com homepage to closely match the approved cinematic reference across laptop, tablet, and smartphone, while preserving the live brand, original approved portrait, working navigation, multilingual controls, authenticated features, data, and disabled Umrah payments.

## Homepage presentation
- Create a premium navy hero with refined transparent panels, cyan/green/gold accents, the original approved portrait placed prominently, and no red styling.
- Lead with “AI-Assisted Web Designer & Developer” and “Websites Built for Real Business.” Add localized Arabic and Hausa equivalents through the existing reviewed translation system.
- Keep “Hire Me” linked to Contact and “View My Work” linked to Projects.
- Retain CMS-managed approved hero media, manual previous/next/indicator controls, swipe and pause behavior; change transitions to gentle cinematic crossfades and disable continuous motion for reduced-motion visitors.
- Place exactly four functional platform cards below the hero in this order: Web Design & AI, Umrah, Business, Community. Use one consistent professional icon per card at every screen size and link each to its real destination.

## Real content and working links
- Recompose the homepage sections to follow the approved reference’s hierarchy, transparent panels, spacing, typography, and card proportions without changing unrelated pages.
- Show only existing approved services, project case studies, photos, and CMS entries. Reference-image sample projects remain unpublished placeholders and will not be copied as claims.
- Keep navigation, dashboard, search, English/Arabic/Hausa controls, More Languages, case-study links, gallery access, carousel controls, and calls to action functional.
- Preserve the visible EN/AR/HA controls on all sizes, Arabic RTL, language persistence, and existing live translation behavior for other enabled languages.

## Media Gallery controls
- Reuse existing approved images instead of creating new artwork; therefore no new generated gallery images are planned.
- Extend Media Gallery records with draft/published status and editable captions through a non-destructive migration, defaulting newly uploaded images to draft.
- Add Super Admin controls to edit captions, publish/unpublish, preview, replace, archive, and delete media.
- Keep replacement on the same permanent media path so all website references update automatically. Keep guarded deletion: referenced media must either remain or have its references deliberately cleared so no broken image URL remains.
- Do not delete existing media or publish new claims/content during this review build.

## Technical details
- Keep current CMS slots, private media storage, signed display links, authentication, roles, RLS, users, Umrah records, and all existing feature logic.
- Add only backward-compatible Media Gallery fields and policies needed for draft/caption management; no destructive data rewrite.

- Record the homepage composition and media lifecycle rules in the project architecture notes.
