# Official Image and Homepage Experience Update

## Goal
Replace every public portrait use with the newly uploaded official images, keep the approved BangisKebbi.com visual direction, and make the homepage shorter and easier to scan.

## Implementation
- Store both uploaded images as optimized CDN assets without retouching, redrawing, cropping, or altering the person’s appearance.
- Use Image 1 as the main hero portrait and any other primary profile presentation.
- Use Image 2 as the secondary community/brand visual; remove references to the prior portrait and app-icon imagery where they serve that role.
- Recompose the existing hero around Image 1 with responsive, uncropped presentation and keep Abuja, Nigeria / Working globally.
- Shorten the homepage into this order: Hero, introduction, services, community, Umrah, BK Foundations, latest activities/video, contact/join.
- Add compact video-thumbnail cards that do not preload or autoplay video; each clearly indicates that verified activity videos will appear when published.
- Keep the existing public content controls and database-fed fallbacks; do not add Phase 2 workflows or sensitive processing.

## Quality Checks
